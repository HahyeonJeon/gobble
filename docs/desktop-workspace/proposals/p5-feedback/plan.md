## P5B — same-design continuation, a later checkpoint

First study and sketch settled stopped Runs only. Design versioned admission history, read-only reuse review and an explicit Resume action. Then qualify stopped tasks, prior successful outputs, changed/missing input/output, tool identity, owner races, repeated command, shutdown, stale review, preserved attempts and old-reader refusal. Failure retries and interrupted-owner reconciliation have distinct output/attempt risks and remain outside the first continuation contract until proved.

Do not enable Resume through the ordinary CLI path or by relaxing its prepared-Run guard. Do not add cross-Run caching while implementing the provenance link.

## Acceptance scenarios for owner review now

- A failed step is selected. Can the User find what actually failed, share it and tell that the Agent's cause is still unconfirmed?
- A completed analysis motivates a supported 30 → 20 bp refinement. Can the User identify the changed setting without reading source and understand what will run next?
- Current has moved since the earlier analysis. Can the User distinguish the design used then from the design being changed now?
- A fresh-run approval appears. Can the User state which data and results location it uses, and that earlier outputs are kept?
- A stopped Run shows future continuation guidance. Can the User distinguish reusing verified work in that Run from starting an analysis with a new design?

Record observed mistakes rather than inferred usability. Owner review is the immediate design input; it does not establish usability for all bioinformatics researchers. Reopen the action model if the origin, adoption or execution boundary is misunderstood.
