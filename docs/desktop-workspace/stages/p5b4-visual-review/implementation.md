## Unit boundaries

Continuation context is the saved review visible alongside an observed task; contracts own its shape and association. Projection is a pure Main function consuming Monitor facts and native review records. The Project review store owns polling/lifecycle only and cannot decide reuse. Controls request a check; the action card alone dispatches explicit User confirmation. Saved context presentation is read-only in all capture/replay consumers.
