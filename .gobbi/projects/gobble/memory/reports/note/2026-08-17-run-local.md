# Local Run session

The session shipped public `Run` for Gobble.

`Run(graph, workspace, cap)` occupies an existing workspace after checks, isolates under `.gobble/`, stages plan-relative paths, runs process and Docker tasks, and persists run state. A second start is `occupied-workspace`, not resume. Cap `0` means `1`. The synthetic fixture runs `alpine:3.21` plus a process task. `testdata/workflow-case/plan.json` is unchanged.

Verification is `go test ./...`. Live Docker tests skip if the daemon is down. The module does not inspect or resume. There is no CLI. See [Design Memory](../../design/README.md) and [Local Run history](../../history/2026-08-17-run-local.md).
