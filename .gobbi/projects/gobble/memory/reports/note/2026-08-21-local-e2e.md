# Local samplesheet e2e pack session

The session added public CSV samplesheet handling and one live-tagged scenario pack so an agent can compose, validate, plan, run, inspect, release, and resume multi-sample RNA (through DEG) and Methyl pipelines from a sheet, through the Go API and the CLI.

Result: package `gobble` owns parse, load, path setter, `IsSampleSheetError`, and `RecordComposeError`. `cmd/gobble` injects `--sample PATH` before zero-arg `Pipeline()` and does not import `assets`. `RNASeq()` and `MethylSeq()` expand one module per sample.
